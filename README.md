# BTU AI Skills Digital Passport

Business and Technology University-ის (BTU) **AI Skills Digital Passport** ჰაკათონის სატესტო პროტოტიპი.

ციფრული პასპორტი, რომელშიც სტუდენტის დადასტურებული AI უნარები შტამპების სახით ინახება. ყოველი ცვლილება ქმნის პასპორტის ახალ ვერსიას, რომლის SHA-256 hash ბლოკჩეინზე იწერება. ამის წყალობით ნებისმიერს შეუძლია შეამოწმოს, რომ პასპორტი ნამდვილია და არავის შეუცვლია.

## გაშვება

ინსტალაცია არ სჭირდება: გახსენით `index.html` ნებისმიერ თანამედროვე ბრაუზერში.

მონაცემები ბრაუზერის `localStorage`-ში ინახება. დასაწყისში დასაბრუნებლად: **BTU ადმინი → საწყისი მონაცემების აღდგენა**.

## ავტომატიკა და ადმინი

შტამპების უმეტესობას სისტემა თავად გასცემს უნივერსიტეტის სასწავლო სისტემის (LMS) მონაცემებით. ადამიანის ჩარევა მხოლოდ იქ სჭირდება, სადაც წესი გადაწყვეტილებას ვერ იღებს.

| შედეგი | გადაწყვეტილება |
|---|---|
| კურსი ჩაბარებულია (ქულა ≥ ზღვარი) | შტამპი ავტომატურად |
| ვორქშოფს სრულად დაესწრო | შტამპი ავტომატურად |
| ქულა ზღვარზე დაბალია / არ დასწრებია / პროექტი ვერ ჩაბარდა | შტამპი არ გაიცემა |
| ნაწილობრივი დასწრება, შეუფასებელი პროექტი, არასწორი ნიშანი, უცნობი სტუდენტი | **ადმინის რიგი** |
| ბუთქემპის პროექტი ჩაბარდა | ადმინის დადასტურებით (წესი ირთვება და ითიშება) |

როლები: **ლექტორი** შედეგებს წერს, **ავტომატიკა** გასცემს შტამპებს, **ადმინი** განიხილავს რიგს, ცვლის წესებს, აუქმებს ვერსიებს და ამატებს გამონაკლისებს. პასპორტში ყოველ შტამპს აწერია, როგორ გაიცა: `Auto-issued · BTU LMS`, `BTU LMS · admin approved` ან `Issued by BTU admin`.

## უნარების სამი ტიპი (BTU-ის კონცეფციიდან)

- **AI Skill (Focused Learning):** ვორქშოფით ან ლაბით განვითარებული კომპეტენცია
- **AI Applied Skill (Applied Learning):** პრაქტიკული პროექტით ან ბუთქემპით დადასტურებული კომპეტენცია
- **AI Advanced Skill (Extended Academic Learning):** აკადემიური კურსით განვითარებული და შეფასებული კომპეტენცია

კატალოგი 12 უნარს შეიცავს, ჰაკათონის საინფორმაციო პრეზენტაციის მიხედვით.

## როგორ მუშაობს ვერიფიკაცია

1. პასპორტის ვერსია JSON-ად იწერება **კანონიკური ფორმით**: გასაღებები ანბანურად, სივრცეების გარეშე.
2. ითვლება **SHA-256** hash.
3. hash იწერება ბლოკჩეინზე. ყოველი ბლოკი წინა ბლოკის hash-ს შეიცავს, ყოველი ვერსია კი წინა ვერსიის hash-ს (`previousHash`).
4. ვერიფიკაციისას hash ხელახლა ითვლება და ბლოკჩეინთან დარდება. ერთი სიმბოლოს შეცვლაც კი სხვა hash-ს იძლევა.

**ბლოკჩეინზე პირადი მონაცემები არ იწერება**, მხოლოდ hash.

## პროტოტიპის შეზღუდვები

- ბლოკჩეინი **სიმულირებულია** ბრაუზერში. რეალურ ვერსიაში გამოიყენება `contracts/PassportRegistry.sol` Polygon Amoy ქსელზე.
- მონაცემთა ბაზის ნაცვლად გამოიყენება `localStorage`. რეალურ ვერსიაში: PostgreSQL + Prisma + Next.js API.
- ვაკანსიასთან შესაბამისობა საკვანძო სიტყვებით ხდება. რეალურ ვერსიაში ამას LLM შეასრულებს.

სრული არქიტექტურა და ნაბიჯ-ნაბიჯ გეგმა: [`docs/AI_Skills_Passport_Step_by_Step_Guide.docx`](docs/AI_Skills_Passport_Step_by_Step_Guide.docx).
